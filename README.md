# Yahya Diallo Portfolio Website

This repository contains my personal portfolio website built to show projects, technical skills, and experience related to data visualization and data analytics.

The site highlights projects completed through coursework, personal work, and dashboard development using tools such as R, Tableau, ArcGIS, HTML, and CSS.

## Website Purpose

The goal of this portfolio is to create a place where recruiters, employers, and others can view my work and learn more about my background and interests in:

- Data Visualization
- Data Analytics
- Data Engineering
- Dashboard Development
- Public Data Projects

## Featured Projects

Some projects currently included on the website:

### NYC 311 Complaints Dashboard
Interactive dashboard created in R using Shiny to analyze NYC 311 complaint data from 2023 and 2024.

### Free Flo Box Dashboard
Interactive Tableau dashboard focused on menstrual health product distribution and usage across underserved communities.

### Dua On The Go
Upcoming mobile app project containing categorized Islamic duas sourced from the Quran and Hadith.
